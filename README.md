# SpotifyClone 🎵

A simple clone of the Spotify UI built using HTML and CSS. This project demonstrates front-end skills by recreating the look and feel of Spotify's homepage.

🔗 **Live Demo**: [Click here to view](https://sameerdevhub.github.io/SpotifyClone/)

## 📌 Features

- Clean and responsive UI
- Custom playlist section
- Working play/pause icons (UI only, no audio)
- Styled buttons and cards
- Footer and header sections
- Interactive hover effects

## 🛠️ Tech Stack

- HTML5
- CSS3

## 🚀 Getting Started

### Prerequisites
No installations required. You just need a modern web browser.

### Running Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/SameerDevHub/SpotifyClone.git
2. Open the index.html file in your browser:
   cd SpotifyClone
   start index.html

That's it! Enjoy exploring the UI.
